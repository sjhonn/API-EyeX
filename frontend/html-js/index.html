Adaptar una paleta de marca

Envía tus siete colores a POST /api/v1/theme/custom. EyeX conserva la identidad visual en lo posible y ajusta los acentos según el modo elegido.

API HTTP

El contrato original sigue disponible. Los parámetros y endpoints nuevos son aditivos.

GET/api/v1/theme/{type}

Parámetros opcionales: severity=mild|moderate|severe, mode=dark|light y high_contrast=true|false.

GET /api/v1/theme/deuteranopia?severity=moderate&mode=dark&high_contrast=true
GET/api/v1/theme/types

Lista los modos disponibles, incluido low_vision.

{"types":["normal","protanopia","deuteranopia","tritanopia","achromatopsia","low_vision"]}
POST/api/v1/theme/custom

Ajusta una paleta propia manteniendo el mismo formato de respuesta del tema.

{
  "type": "protanopia",
  "palette": { "background": "#101820", "surface": "#182430", "text": "#F8F9FA", "primary": "#E63946", "secondary": "#2A9D8F", "error": "#D62828", "success": "#2A9D8F" }
}
POST/api/v1/test/suggest

Devuelve una sugerencia orientativa a partir de cuatro preguntas. No es un diagnóstico médico.

{"suggested_type":"tritanopia","disclaimer":"Resultado orientativo. No es un diagnóstico médico."}
POST/api/v1/simulate

Simula un color con severidad continua de 0 a 1 mediante el modelo machado-2009.

{"hex":"#FF0000","type":"protanopia","severity":0.65}
POST/api/v1/simulate/batch

Simula de 1 a 256 colores usando el mismo tipo y severidad.

{"colors":["#FF0000","#00FF00"],"type":"deuteranopia","severity":0.5}

Test rápido orientativo

Marca las situaciones que reconoces. El resultado solo sirve como guía para elegir un tema de prueba.

Integración rápida

CSS estático

Para usar paletas predefinidas sin llamadas HTTP:

<link rel="stylesheet" href="https://TU_HOST/eyex.css">
<html data-eyex-theme="deuteranopia" data-eyex-mode="dark">

Widget embebible

El script detecta la misma URL donde está alojada la API y añade un botón flotante:

<script src="https://TU_HOST/eyex.js"></script>
