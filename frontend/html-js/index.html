Tema de pantalla para visión de color

Una paleta completa para activar modo daltónico.

EyeX devuelve siete colores coordinados para aplicar el tema completo de una interfaz. El cliente elige un tipo de visión y recibe una paleta lista para usar como variables CSS.

Contrato de la API

Dos endpoints, respuestas pequeñas y el mismo formato en Go, PHP, TypeScript y Java.

GET/api/v1/theme/{type}

Devuelve la paleta completa del modo solicitado.

{
  "type": "deuteranopia",
  "palette": {
    "background": "#1E1E1E",
    "surface": "#2A2A2A",
    "text": "#F5F5F5",
    "primary": "#4A90D9",
    "secondary": "#D9A24A",
    "error": "#D94A4A",
    "success": "#4AD98C"
  }
}
GET/api/v1/theme/types

Lista los modos disponibles en el contrato público.

{
  "types": [
    "normal",
    "protanopia",
    "deuteranopia",
    "tritanopia",
    "achromatopsia"
  ]
}

Error de tipo

{
  "error": "invalid_type",
  "message": "Tipo de daltonismo no soportado"
}

Integración en frontend

Guarda el modo elegido por el usuario, solicita una sola paleta y aplica sus valores al elemento raíz de la página.

  1. Consulta /api/v1/theme/types.
  2. Solicita /api/v1/theme/deuteranopia o el modo elegido.
  3. Asigna cada color a una variable CSS global.
  4. Reutiliza esas variables en todos los componentes de la interfaz.
const data = await fetch(
  "/api/v1/theme/deuteranopia"
).then(r => r.json());

for (const [name, value] of
     Object.entries(data.palette)) {
  document.documentElement.style
    .setProperty(`--eyex-${name}`, value);
}
